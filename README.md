# numerical-simulation

> Numerical simulation in Python: RC circuit (Euler vs RK4 vs analytic, CustomTkinter GUI) and a pendulum mechanics model.

## `basics/` — RC circuit simulator
- Analytic solution vs **Euler** vs **Runge-Kutta 4**, error comparison
- Interactive **CustomTkinter** GUI with embedded matplotlib plots, parameter input (R, C, E, V0), data export

## `mechanics/` — pendulum
- Time integration of a **damped pendulum** (g, length, mass, initial angle / velocity), θ(t) plotted for several damping coefficients λ

## Stack
Python · NumPy · matplotlib · Tkinter / CustomTkinter
